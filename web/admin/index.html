Konfigurasi Endpoint MCP & Cloudflare Tunnel

Didapatkan otomatis saat menjalankan d:\VIDORA\start_mcp_hermes.bat di komputer/server Anda.
Protokol FastMCP SSE transport.
1 Jalankan Server di PC

Klik 2x file d:\VIDORA\start_mcp_hermes.bat. Tunggu sampai muncul URL publik .trycloudflare.com/sse.

2 Daftarkan di SumoPod

Buka Web Console SumoPod, jalankan hermes mcp add vidora --url ... lalu verifikasi via hermes mcp list.

3 Chat Telegram Bot

Buka Telegram Bot Hermes Anda dan langsung beri perintah suara atau teks: "Hermes, generate video produk skincare 9:16 pakai VIDORA."

Daftar 6 Tools MCP VIDORA yang Disediakan untuk Hermes AI:

6 Tools Aktif
vidora_generate_video Video Engine
Generate video AI sinematik (Omni Flash / Veo) format 9:16 vertikal, 16:9, atau 1:1.
Params: prompt (req), aspect_ratio, model
vidora_generate_image Studio Photo
Generate foto produk studio AI kualitas tinggi (Nano Banana Engine).
Params: prompt (req), aspect_ratio
vidora_generate_prompt Prompt AI
Analisa foto produk via Gemini Vision untuk menyusun prompt video/gambar otomatis.
Params: product_name (req), usp, category
vidora_list_accounts Vault Accounts
Melihat status seluruh akun Google vault yang terhubung di VIDORA.
Params: filter_status (all, ready, limit)
vidora_get_job_status Render Monitor
Memeriksa progres (%), status rendering, dan link download MP4 file hasil video.
Params: job_id (req)
vidora_cleanup_storage Cloud Storage
Membersihkan file Cloudflare R2 yang sudah lebih dari 3 hari agar kuota storage aman.
Params: days_older (default: 3)
